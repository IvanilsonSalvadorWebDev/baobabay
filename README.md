# Baobabay – Vite + Vercel

1. Copie as imagens para `public/images/` (ver LEIA-ME.txt).
2. `npm install` e `npm run dev` (para testar o formulário localmente use `npx vercel dev`).
3. Envie para o GitHub e importe o projecto na Vercel (Framework: Vite).
4. Em Vercel > Settings > Environment Variables, defina as variáveis de `.env.example`
   (SMTP_*, MAIL_FROM, MAIL_TO, SITE_URL, VITE_WHATSAPP_NUMBER) e faça novo deploy.
5. Substitua os `href="#"` das redes sociais pelos links reais em `index.html`.
